EPA data service

Data comes from the EPA Clean Air Markets Program Data (CAMPD) service. The app requests annual unit-level emissions, then stores them in the local SQLite database through the back end.

  1. Request annual emissions for the chosen state and years.
  2. Check each record and skip incomplete ones.
  3. Save facilities, units and yearly emissions to the database.
